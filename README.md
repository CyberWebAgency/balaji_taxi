# Balaji Taxi & Tempo Traveler Website

A modern, responsive website for Balaji Taxi & Tempo Traveler services in Mathura, showcasing their taxi services, tempo travelers, and tour packages.

## Features

- Fully responsive design that works on all devices (mobile, tablet, desktop)
- Modern and clean UI with smooth animations
- Mobile-friendly navigation
- Vehicle fleet showcase
- Tour package listings
- Gallery with lightbox functionality
- Contact form with validation
- FAQ accordion
- Testimonials slider
- Call to action sections

## Pages

1. **Home** (index.html) - Overview of services and key information
2. **About Us** (about.html) - Company history, mission, values, and team
3. **Services** (services.html) - Detailed listing of all services offered
4. **Tour Packages** (tour-packages.html) - All available tour packages
5. **Vehicles** (vehicles.html) - Fleet showcase with details and pricing
6. **Gallery** (gallery.html) - Photos and videos of vehicles and destinations
7. **Contact** (contact.html) - Contact form, location map and information

## Setup Instructions

1. Add images to the corresponding folders:
   - `/images/services/` - Service-related images
   - `/images/vehicles/` - Vehicle images
   - `/images/packages/` - Tour package images
   - `/images/testimonials/` - Customer testimonial photos
   - `/images/about/` - About page images (team, company photos)

2. Update contact information:
   - Phone numbers
   - Email addresses
   - Office address
   - Google Maps embed link in contact.html

3. Update social media links in the header and footer
